# Секвенции ингредиентов для монтажа

Размер каждого кадра — **640×1080 px**, то есть одна треть видео 1920×1080 по горизонтали.

## Состав

- `index.html` — исходный HTML-шаблон и встроенные SVG-пиктограммы.
- `fonts/` — Flame и Golos Text: папка самодостаточна, курс ей не нужен.
- `tools/render.js` — перерендер всех кадров с теми же именами.
- `frames/angus/` — 9 накопительных кадров Ангуса.
- `frames/pita/` — 8 накопительных кадров Питы.
- `frames/bigking/` — 10 накопительных кадров Биг Кинга.

Имена кадров имеют сквозную внутри блюда нумерацию `001`, `002` и далее. Каждый следующий PNG содержит предыдущую сборку и один новый ингредиент. Строки всегда перестраиваются в фактический порядок блюда: от верхней булочки или половины тортильи до нижней.

Верхняя и нижняя часть булочки (тортильи) разделены пунктиром с подписями «↑ Верх» / «Низ ↓». Граница — `SPLIT` в `index.html`: всё с `order` меньше 35 относится к верхней части.

Высота строки считается под блюдо по его последнему кадру и одинакова во всех кадрах этого блюда, чтобы строки не прыгали при монтаже: у Питы (9 строк) они крупнее, у Биг Кинга (11 строк) — плотнее. Длинное название ужимается, если не влезает рядом с порцией.

Для Ангуса и Ангус Питы порция жареных грибов указана как **2 ложки · 40 г**.

## Предпросмотр отдельного кадра

Открой `index.html` через локальный сервер с параметрами:

```text
?dish=angus&step=1
?dish=pita&step=5
?dish=bigking&step=10
```

Параметр `render=1` скрывает управление и оставляет только панель 640×1080.

## Перерендер кадров

```bash
cd video-ingredient-sequences
python3 -m http.server 8777 &
node tools/render.js        # нужен puppeteer-core и Google Chrome
```

Кадры перезаписываются по тем же путям, что указаны в `manifest.json`, — клипы в Resolve подхватят их после смены корневого пути.

## Палитра

Использованы сезонные токены курса (`course/css/tokens/palette.css`): `shroom`, `rust`, `cap`, `moss` и `honey`. Заголовки набраны локальным Flame, основной текст — Golos Text.
